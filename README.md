### Featured Projects

**[Distributed Multiplayer Game Engine](https://github.com/Blazikengr8)** — `Python` `Sockets` `TCP/IP` `Multi-threading`  
Server-authoritative multiplayer engine synchronizing real-time game state over raw TCP/IP sockets, using multithreaded concurrency control and a compact custom serialization format to keep client/server handshake latency under 15ms.

**Multi-Modal Vector Space Integration** — `PyTorch` `Docker` `CI/CD` `RAG`  
Cross-modal embedding service mapping audio and text into a unified vector space for low-latency semantic search, containerized and backed by CI-enforced unit/integration tests, benchmarked at a 10% performance lift over baseline architectures.

**[Weather Pulse](https://github.com/Blazikengr8)** — `Swift` `SwiftUI` `CoreLocation` `Node.js`  
Native iOS weather app with a hybrid SwiftUI/Highcharts visualization engine and a cloud-backed favorites system on a Node.js/Express API.

**[LockIn ⚡](https://github.com/Blazikengr8/lockin)** — `Flutter` `Firebase` `HealthKit`  
73-day 1v1 fitness accountability app with a Feature-First Clean Architecture, Firebase backend, and native HealthKit/Health Connect data syncing. *(Native iOS/SwiftUI migration in progress.)*
